# Markr Demo 演示图库

## 身份与范围

这是**不能登录的演示展示身份**，不是已注册账号。固定 owner 为 `markr-demo`，主页名为“Markr Demo · 演示图库”；没有邮箱、密码、验证邮件、会话或持久访问凭据。种子不读取或写入 identity 表，不绕过真实用户验证。当前用户仍需使用既有正常注册流程建立自己的账号。

本组 10 张网图仅用于私网界面占位，6 横、4 竖，分为 3 个作品集。Markr Demo 是选图展示身份，不是摄影原作者；作品标题、正文、主页及来源区均标明演示。全部逐张核实 CC0，不添加“未使用 AI”声明，不套用平台的 CC BY 4.0 标签；`license` 和 `aiDeclaration` 为 null，实际许可保存在逐图来源字段。

下载的是 Wikimedia 现成中等尺寸 JPEG（最长边 1280–1440px），合计 2,871,464 bytes，约 2.74 MiB；不是摄影原片。种子保留下载版本，再生成最长边不超过 1800px、质量 82 的 WebP 展示图并移除元数据。不开启原文件下载，不将照片字节提交仓库。封面和列表可裁切，观看页保留完整图幅。

## 可重复执行与清理定位

脚本只接受显式的现有数据目录，默认只读预检；8–12 张、2–3 个作品集、单文件 5 MiB、总输入 35 MiB、最多 40MP 解码限制。源文件 SHA256、来源域名、许可名称与地址匹配均须通过。独立 owner、确定性 ID 和种子摘要必须一致；碰撞、被修改或不完整的数据会拒绝写入。数据库事务与独占文件创建保护已有内容；可处理的失败仅撤销本次新建文件。

```sh
cd /home/timestarry/deploy/markr-phase1/current
node scripts/seed-demo.mjs \
  --directory /home/timestarry/deploy/markr-phase1/trial-data \
  --manifest ops/demo/manifest.json \
  --images /home/timestarry/deploy/markr-phase1/demo-sources/markr-demo-v1
```

审核只读输出后，同一命令追加 `--apply` 才导入。完全相同的清单再次运行返回 unchanged；不更新时间、不重复插入、不覆盖文件。原正式 data 不作为此演示任务的目标。

清理只提供可审查的定位报告，不执行删除：

```sh
node scripts/seed-demo.mjs \
  --directory /home/timestarry/deploy/markr-phase1/trial-data \
  --manifest ops/demo/manifest.json --cleanup-plan
```

报告列出 `markr-demo-v1` 的记录、预期媒体路径、缺失或冲突以及其他记录的引用。不能按通配符删除用户媒体，不能删除整个 trial-data。真正撤回数据前应备份 SQLite/WAL 和媒体，确认外部引用，再按报告处理；本次没有删除任何既有内容。应用版本回退保留演示数据，展示内容撤回是独立操作。
