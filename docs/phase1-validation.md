# 首期预览验证记录

## 验证结论

这是持久化 API 与页面基础预览。身份入口尚未授权和启用，不能视作完整首期验收。没有创建真实账户、会话密钥或临时生产测试账户。生产写接口必须拒绝未认证请求。

## 自动化覆盖

`npm test` 使用 Node 测试运行器运行以下 2 项集成测试，在 Mac 和 server 上均通过。测试监听独立临时端口，使用临时 SQLite 与媒体目录；测试身份只在测试应用构造时注入，生产应用不接收身份请求头。

| 测试 | 已覆盖行为 |
| --- | --- |
| 持久化发布与权限转换 | 主动 multipart 上传真实 JPEG；带 EXIF 的原文件逐字节保留；优化图不带 EXIF；默认原件下载拒绝；草稿隐藏；跨作者更新和素材引用拒绝；公开发布进入广场；关闭广场后可直接访问；仅链接不进广场和主页；公开作品集过滤私密成员；作者可读自己私密成员；作者显式开启原件后可下载；改回私密或草稿后展示图与原件请求拒绝；媒体响应 no-store；公开 API 隐藏私有作者标记，作者工作台保留，伪造系统来源被拒绝；作者 AI 自声明与 CC BY 官方链接持久化，非法许可代码拒绝；重复素材引用拒绝；空作品发布拒绝；损坏图片拒绝且没有额外素材记录；数据库关闭重开后对象仍存在 |
| 默认身份入口 | 默认生产应用不接受 `x-test-viewer` 或 `x-user` 冒充身份，工作台返回 401 |

目前元数据样本含普通 EXIF，未用真实含 GPS 的用户照片进行验证；Sharp 展示转换不保留整个 EXIF。原件可能含 GPS，原件开关旁有明确提示。API 仅返回逻辑素材 ID、格式、尺寸和字节数，不返回磁盘路径。

`npm run check` 检查 3 个服务端模块语法；`npm run build` 成功构建 Vue 页面。仓库没有 ESLint、TypeScript 或独立类型检查，因此不能称 lint 或类型检查已通过。Vite 5 与 Sass 有弃用提示。兼容范围内执行过 `npm audit fix`；服务器生产依赖安装报告 0 漏洞，开发依赖 Vite/esbuild 仍有审计问题，需要单独升级验证。

## UI 与部署验证

浏览器归属为用户 Mac 上已有 Microsoft Edge、用户配置 1，通过 CUA 自动化新建验证标签。曾尝试 Chrome，但该控制环境没有 Chrome。已在 Edge 打开 Mac 本地实例和经 SSH 转发的服务器实例，观察广场深色空状态、工作台身份关闭状态、水印工具入口。未使用云端浏览器。

离线工具选择合成 PNG 的文件上传调用因扩展未启用 `Allow access to file URLs` 失败，且工具长时间未返回；没有更改扩展权限。不能计为图片处理、导出、拼图功能或移动端 UI 验收通过。

服务器 `markr-phase1.service` 健康、首页 200、工作台 401，监听仅 `127.0.0.1:18140`。最终交接版本执行用户级服务重启，再检查健康、缓存和同一持久化目录。SQLite 重开持久化验证来自集成测试；生产没有账号或用户作品，所以不能称真实用户上传在服务重启后恢复已验收。
