# 子项目 2 实施计划：观看器

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新前端 `web/`（Vue 3 + TS）里的完整观看器 `/c/:id`，由 `markr serve` 通过 `internal/webui` 内嵌提供，并有 Playwright 在 Chromium 和 WebKit 上的验收。

**Architecture:** 纯逻辑（手势状态机、格式化、档位选择、URL 状态）写成无 DOM 的 TS 模块并单测；Vue 组件只做渲染和事件转发；路由组件负责数据获取。Go 侧新增 `internal/webui`，挂在现有 API handler 之后作为非 `/api`、`/m` 路径的回退。

**Tech Stack:** vue 3.5.44, vue-router 4.6.4, vite 7.3.7, @vitejs/plugin-vue 6.0.10, typescript 5.9.3, vue-tsc 3.3.13, vitest 5.0.5, happy-dom 21.0.3, @vue/test-utils 2.5.1, @playwright/test 1.64.1。Node 22（本机 22.23.2）。Playwright 的 Chromium 与 WebKit 已安装在本机缓存。

**Spec:** `docs/superpowers/specs/2026-10-15-sp2-viewer-design.md`（上位：`2026-10-13-markr-redesign-design.md` §3、§7）。API 形状以 `.superpowers/sdd/2026-10-13-sp1-go-foundation/task-13-report.md` 为准；冲突时以 Go 代码为准，并停下报告。

- 所有面向用户的文案是中文，与规格一致。

## Review Focus

1. **滚轮/触控板多翻**：惯性滚动必须被 500ms 锁和累计阈值吸收 —— 任务 3 单测 + 任务 8 Playwright 连续 20 次 wheel。
2. **隐私**：前端不得预取原图，不得在任何地方渲染位置信息 —— 任务 6/7 组件测试 + 任务 8 网络请求断言。
3. **焦点与读屏**：边缘自动隐藏时，键盘焦点所在的边不能隐藏；翻帧必须播报 —— 任务 5/6。
4. **SPA 回退吞掉 API**：`/api/*`、`/m/*` 的 404 必须仍是 JSON，不能回退成 `index.html` —— 任务 2。
5. **CSP 挡图**：CDN 与 S3 预签名主机必须在 `img-src` 里，否则生产环境一张图都显示不出 —— 任务 2 单测 + 任务 8 冒烟。

### Task 4: 输入状态机

**Files:**
- Create: `web/src/viewer/gesture.ts`, `web/src/viewer/gesture.test.ts`, `web/src/viewer/input.ts`, `web/src/viewer/input.test.ts`

**Interfaces:**
- `gesture.ts`（无 DOM）：
  ```ts
  type Axis = 'y' | 'x'
  type Intent = { kind: 'frame', dir: 1 | -1 } | { kind: 'collection', dir: 1 | -1 }
  interface GestureConfig { viewportW: number; viewportH: number; reducedMotion: boolean;
    distanceRatio: 0.2; velocity: 0.4; lockPx: 10 }
  class PointerGesture {
    constructor(cfg: GestureConfig)
    start(x: number, y: number, t: number): void
    move(x: number, y: number, t: number): { axis: Axis | null; offset: number } // offset 为跟手位移；reducedMotion 时恒为 0
    end(x: number, y: number, t: number): Intent | null
    cancel(): void
  }
  class WheelAccumulator {
    constructor(opts?: { threshold?: 60; lockMs?: 500 })
    push(e: { deltaX: number; deltaY: number; deltaMode: 0 | 1 | 2; t: number }): Intent | null
  }
  function keyIntent(key: string, shift: boolean): Intent | { kind: 'home' } | { kind: 'end' } | null
  ```
  方向约定：内容向上滑（y 变小）→ 下一帧（dir 1）；向左滑 → 下一组（dir 1）。`deltaMode` 1/2 时一格即触发。锁定期内的事件被吞掉且不累计；锁结束后累计从 0 开始。轴未锁定前 `end` 只看位移较大的轴。
- `input.ts`：`bindInputs(el: HTMLElement, handlers: { intent(i): void; drag(axis, offset): void; tap(): void; doubleTap(): void }, cfg)` 返回解绑函数；用 Pointer Events（`touch-action: none` 由组件设置）、`wheel`（`passive: false` 并 `preventDefault`）、`keydown`（挂 `window`，忽略来自 `input/textarea/[contenteditable]` 的事件）；单击判定：位移 < 10px 且 < 250ms；双击 300ms 内两次单击。支持 `canScrollInner(dir)` 回调：`pair` 帧内部还能滚动时不产生 frame intent。

- `InfoLayer`：≥1024px 为右侧 360px 面板（Viewer 舞台宽度同步减小，用 CSS 变量），否则底部抽屉（最高 60vh，下滑关闭）；内容按规格 §5.3；`pair` 帧可在照片间切换；`text` 帧只显示合集信息；`role="dialog"`、`aria-modal="false"`、带标题；打开时焦点进入，关闭后焦点还给触发者。
- `Histogram.vue`：SVG，亮度 / RGB 切换按钮（`aria-pressed`），RGB 三条半透明曲线叠加，`role="img"` 带 `aria-label="直方图"`；`histogram=null` 不渲染。
- `EndFrame`：合集名 · 张数；「从头再看」（go(1)）、「作者主页」、「下一组 · 标题 · 作者」（带封面，emit `navigate(1)`）；没有 next 时第三项为「回到墙」（emit `exit`）。preview 模式只显示「从头再看」。
- 跨作者：Viewer 在 `collection.owner.id` 变化时调用 `flashTop(1500)`，并在 live 区写入「{作者} 的「{合集名}」」。
- 键盘：`i` 切换信息层、`f` 全屏、`Esc` 按「菜单 → 信息层 → 全屏 → exit」顺序处理。
