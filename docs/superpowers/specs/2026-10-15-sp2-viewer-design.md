# 子项目 2：观看器

日期：2026-10-15　上位文档：[整体重构设计](2026-10-13-markr-redesign-design.md)（§3 观看器、§7 视觉语言、§10 验收）　依赖：[子项目 1](2026-10-13-sp1-go-foundation-design.md)（§7 读取 API）

## 1. 目标与边界

交付新前端的骨架和完整的观看器：打开 `/c/{collectionId}`，在黑色全视口里纵向逐帧观看一个合集，横向切换到同一面墙上的相邻合集，四条边按需出现，右侧信息层，结尾帧。

**完成标准**
- Demo 种子或任意已发布合集，都可以在真实浏览器里用触屏、触控板、鼠标、键盘完整看完，并切换到相邻合集。
- Playwright 在 Chromium 和 WebKit 上跑完 §9 的验收矩阵，并在 360、390、768、1440 四种宽度下产出截图。
- 观看路由首屏 JS ≤ 80 KB（gzip），首帧图片走高优先级加载。
- `markr serve` 直接提供构建好的前端，不需要单独的静态服务器。

**不在本子项目**
- 展墙（广场、主页、作品集页）：子项目 3，可以并行开发。本子项目的「返回」先回到 `/`，再按 §6.4 的约定交给子项目 3 恢复位置。
- 策展台的访客视角预览：子项目 4 复用本子项目的 `Viewer` 组件，这里只保证组件可以接收注入的数据。
- 登录、上传等界面：子项目 3 和 4。
- 旧的 `src/` 前端保持不动，到子项目 6 再移除。

## 2. 技术与目录

```
web/                       新前端（独立 package.json）
  src/
    main.ts  App.vue  router.ts
    api/          类型化的读取客户端（只覆盖本子项目用到的端点）
    viewer/       Viewer.vue 及其子组件、手势状态机、媒体选择、预载
    ui/           设计令牌（tokens.css）、基础排版、图标（内联 SVG）
  e2e/            Playwright 用例、夹具 JSON、生成的测试图片
internal/webui/   Go：go:embed all:dist（Vite 输出到 internal/webui/dist，仓库只提交 dist/.gitkeep），SPA 回退
```

- Vue 3 + TypeScript strict + Vue Router + Vite，不引入 UI 库和状态库，样式用原生 CSS 加自定义属性。依赖锁定为互相兼容的精确版本：vue 3.5.44、vue-router 4.6.4、vite 7.3.7、@vitejs/plugin-vue 6.0.10、typescript 5.9.3、vue-tsc 3.3.13、vitest 5.0.5、happy-dom 21.0.3、@vue/test-utils 2.5.1、@playwright/test 1.64.1。
- 单元测试用 Vitest + happy-dom，真实浏览器验收用 Playwright。
- 开发时，Vite 把 `/api` 和 `/m` 代理到 `127.0.0.1:18150`（`markr serve`）。
- 生产时，`internal/webui` 嵌入 `web/dist`。除 `/api/`、`/m/` 外的 GET 请求，先查对应的静态文件，查不到就返回 `index.html`。静态资源（带内容哈希的文件名）设 `Cache-Control: public, max-age=31536000, immutable`，`index.html` 设 `no-cache`。没有构建产物（只有 .gitkeep）时，Go 照常编译和启动，前端路由返回一页「前端未构建」的 503 提示。
- 安全头：在现有基础上，为 HTML 响应加 CSP：`default-src 'self'; img-src 'self' {CDN_BASE} {S3 预签名主机} data:; style-src 'self'; script-src 'self'; connect-src 'self'; frame-ancestors 'none'`。预签名主机从配置推导。

## 3. 视觉令牌（暗房）

| 令牌 | 值 |
| --- | --- |
| `--bg-view` | `#000`（观看器） |
| `--bg-wall` | `#0b0b0c`（墙和工作台，子项目 3 起使用） |
| `--fg` / `--fg-muted` / `--fg-faint` | `#e8e6e1` / `#9a978f` / `#5c5a55`（faint 只用于装饰） |
| `--accent` | `#c9cfc0`（焦点环、主操作） |
| `--line` | `rgba(232,230,225,.14)` |
| 字体 | 标题 `"Songti SC","Noto Serif SC","Source Han Serif SC","Iowan Old Style",Georgia,serif`；正文和控件为系统无衬线字体；参数和序号用 `ui-monospace,"SF Mono",Menlo,monospace`，加 `font-variant-numeric: tabular-nums` |
| 动效 | 位移 `cubic-bezier(.2,.7,.2,1)` 280ms，淡入淡出 180ms；`prefers-reduced-motion` 下全部改为 0ms 的即时切换 |
| 间距 | 4/8/12/16/24/32/48 |

不加载任何网络字体。普通文字的对比度不低于 4.5:1，图片上方的边缘文字依靠局部暗渐变来保证对比度。

## 4. 路由与数据

- `/c/:id`，查询参数：`wall=square|user|album:{albumId}`（入口上下文）、`f={帧序号，从 1 开始}`。
- 切换帧时，用 `history.replaceState` 更新 `f`。横向切换合集时，用 `pushState` 进入新的 `/c/:id`，`wall` 保持不变，这样浏览器的后退键能回到上一组。
- 分享链接只包含 `/c/:id` 和可选的 `f`，不带 `wall`，与上位 §3.2 一致。
- 数据：
  - `GET /api/collections/{id}`
  - `GET /api/collections/{id}/neighbors?wall=…`：取 `prev`、`next` 和 `strip`。响应里的 `wall` 是实际采用的墙，前端以它为准。
  - `GET /api/photos/{id}/original?collection={cid}`：下载原图。
- 错误：404 显示一屏黑底提示「这组照片不存在或已不再公开」，提供回到首页的链接。网络错误显示同样的整屏提示，并提供「重试」。
- 预取：当前帧解码完成后，预载前后各一帧所选档位的图片。横向的相邻合集只预取 `GET /api/collections/{id}` 和它首帧的图片。原图永远不预取。

## 5. 画面

### 5.1 帧与版式
- 观看区是整个视口，背景为 `--bg-view`。安全边距：宽度 ≥ 768 时为 24px，窄屏为 0–8px，并且要避开 `env(safe-area-inset-*)`。
- `full`：图片以 contain 方式铺满可用区域。
- `matted`：画面占比为 `matteRatio`，居中，四周留黑。
- `pair`：2–3 张横向并排，等高，间距 12px。竖屏且宽度 < 600 时，改为纵向堆叠，在同一帧里纵向滚动。
- `text`：标题字体，居中排版，最大宽度 32em，行高 1.9，颜色 `--fg`。
- 图片用 `<picture>`，按 AVIF → WebP → JPEG 的顺序给出 `source`，每种格式都带四档 `srcset`（宽度描述符）和 `sizes`，由浏览器选档。首帧用 `fetchpriority="high"`、`decoding="async"`，其他帧懒加载。
- 每张图都声明 `width`、`height`（来自 media），保证占位比例不跳动。图片加载完之前显示纯黑，不用骨架屏或闪烁动画。
- 图片无法加载时，在原位置显示一行细字「图片暂时无法加载」，不影响翻页。

### 5.2 四条边

边缘元素默认隐藏，以下情况出现：指针进入距该边 72px 的区域、键盘获得焦点、触屏单击画面（四边同时切换显示/隐藏）。指针静止 2 秒后，四边和光标一起淡出；有菜单或信息层打开时不淡出。

| 边 | 内容 |
| --- | --- |
| 上 | 返回、合集名 · 作者、`⋯` 菜单（复制链接、下载原图（仅当前照片 `downloadable` 时显示）、作者主页） |
| 左 | 本组的位置刻度，每帧一条短线，当前帧高亮，显示 `03/12`。可点击跳转，超过 40 帧时改成按比例的连续刻度条 |
| 右 | 竖排参数线，例如 `35mm · f/2 · 1/250 · ISO 200`。只显示当前帧公开的字段，一个都没有时这条边整体不渲染。点击打开信息层 |
| 下 | 相邻合集的封面带（`strip`），当前合集高亮，点击切换。只有一个合集时不渲染 |

切换到另一位作者的合集时，上边自动显示约 1.5 秒后再淡出，并保证读屏软件能读到新的作者名。

### 5.3 信息层
- 打开方式：`i` 键、点击参数线，或在触屏上从底部上滑。关闭方式：`Esc`、再按一次 `i`、点击关闭按钮，或下滑。
- 宽度 ≥ 1024 时，信息层是右侧 360px 的面板，观看区同步缩窄，画面不被遮挡。较窄时，改为底部抽屉，高度最多 60vh，可以拖动。
- 内容依次为：标题、图注、作者 · 合集 · `n/m`，然后是直方图（SVG，亮度和 RGB 两种视图可切换，RGB 用三条半透明曲线叠加），接着是公开参数表（两列，等宽数字），最后是许可、AI 声明和原图下载入口。
- 当前帧是 `pair`（多张图）时，信息层显示其中第一张，并可以在几张之间切换。`text` 帧不显示参数线，信息层只有合集信息。
- 位置信息永远不显示，因为 API 本来就不返回。
- I7 拍摄日期在接近当地午夜时可能差一天：已在 SP4a 修复（按 EXIF 偏移取当地日期），需重新处理旧照片。

### 5.4 结尾帧

最后一帧之后再加一帧：合集名 · 张数，下面三个入口：「从头再看」「作者主页」「下一组 · 标题 · 作者」（带封面）。在结尾帧上继续向下或向右，都会进入下一组。没有下一组时，第三个入口改为「回到墙」。

## 6. 交互

### 6.1 输入

| 输入 | 帧（纵向） | 合集（横向） |
| --- | --- | --- |
| 触屏 | 上下滑动：位移超过视口高度的 20%，或速度超过 0.4 px/ms，就翻页，否则回弹。画面跟手移动 | 左右滑动：同样的阈值，按视口宽度计算。跟手时，下一组的首帧从侧面露出来 |
| 触控板 | 累计 `deltaY`，单次超过 60px 翻一帧，翻页后锁 500ms，用来吸收惯性滚动 | 累计 `deltaX`，同样的规则 |
| 鼠标滚轮 | `deltaMode` 为行或页时，滚一格就翻一帧，同样带 500ms 锁 | 点击底部封面带 |
| 键盘 | `↓`/`PageDown`/`Space` 下一帧，`↑`/`PageUp`/`Shift+Space` 上一帧，`Home`/`End` | `←`/`→` |

其他按键：`i` 打开或关闭信息层，`f` 进入或退出全屏，`Esc` 依次关闭菜单、信息层、全屏，最后返回墙。双击画面也会进入或退出全屏。

- 手势方向在移动超过 10px 后锁定，之后只响应一个方向。`pair` 帧内部的纵向滚动优先：滚到边界后，再继续滚才翻帧。
- 所有输入都通过同一个状态机（`idle → tracking → settling`）处理，它和 DOM 解耦，可以单独做单元测试。
- 开启减少动态效果时，不做跟手位移，达到阈值后直接切换。

### 6.2 无障碍
- 观看区的 role 为 `region`，带 `aria-roledescription="合集观看"`。每次翻帧时，用 `aria-live="polite"` 播报「第 3 帧，共 12 帧」以及图注或标题。
- 每个边缘元素都是真实的按钮或链接，带中文 `aria-label`。用 Tab 可以依次聚焦这些元素，聚焦时对应的边会显示出来。
- 焦点环为 2px 的 `--accent` 加 2px 偏移，在黑底上清晰可见。
- 触控目标不小于 44×44px。功能都不依赖 hover。
- 平台限制：元素全屏时，浏览器会自己消费 `Esc` 来退出全屏，通常不会把按键交给页面，所以全屏状态下无法做到「先关闭信息层」，按一次 `Esc` 会直接退出全屏。

### 6.3 全屏与系统
- 全屏使用 Fullscreen API，不支持的设备上隐藏这个入口。
- 文档标题为 `合集名 · 作者 — Markr`。
- 通过 `navigator.share` 分享，不支持时改为复制链接，并显示 1.5 秒的提示。

### 6.4 与墙的约定（供子项目 3 使用）
- 离开观看器时，写入 `sessionStorage['markr:lastViewed:'+wall] = collectionId`。子项目 3 的墙读取这个值，滚动到对应合集并把焦点放在它上面。
- 「返回」的规则：如果是从站内某面墙进来的（`history.state.fromWall`），就执行 `history.back()`；否则导航到这面墙对应的路由。本子项目里，这些路由还不存在时一律回到 `/`。

## 7. 组件可复用性

`Viewer.vue` 只接收 props：`collection`、`neighbors`、`initialFrame`、`mode: 'public'|'preview'`。数据获取放在路由组件 `CollectionRoute.vue` 里。子项目 4 的访客视角预览直接传入编辑中的数据，并使用 `mode=preview`。preview 模式下关闭横向切换、URL 同步和预载相邻合集。

## 8. 性能与健壮性
- 观看路由单独打包。首屏 JS 不超过 80 KB（gzip），在 CI 里检查。
- 同一时间最多保留 5 帧的 `<img>` 节点：当前帧，以及前后各两帧。其余帧只保留尺寸占位。
- 窗口尺寸变化或旋转屏幕时，不重新请求数据，只重新排版。
- 内存：总帧数超过 200 时，刻度条和预载窗口都保持固定大小。

## 9. 验收

**单元测试（Vitest）**：手势状态机（阈值、方向锁、惯性锁、减少动态效果）；档位选择；参数线格式化（快门 `1/250`、`0.3"`、焦距 `35mm`、等效焦距、光圈 `f/2`、ISO）；直方图转成 SVG 路径；URL 状态读写；`sessionStorage` 约定。

**真实浏览器（Playwright，Chromium + WebKit）**：Playwright 拦截 `/api` 和 `/m`，返回夹具 JSON 和生成的测试图，保证结果确定、可重复。另有一条冒烟用例，连真实的 `markr serve` 加 Demo 种子跑完整链路。

| 场景 | 断言 |
| --- | --- |
| 宽度 360/390/768/1440，横图、竖图、全景、`pair`、`text` | 截图；图片完整显示在安全区内（`boundingBox` 检查）；页面没有横向滚动 |
| 键盘全流程 | 只用键盘就能看完一组、打开信息层、切到下一组、返回；每一步焦点都可见 |
| 滚轮 | 一次滚轮事件只翻一帧；连续 20 次 deltaY 也不会多翻 |
| 触屏（WebKit 移动端模拟） | 上滑翻帧；短距离慢滑回弹；左滑切换合集；单击切换四边显示 |
| 边缘显隐 | 指针靠近左边时刻度出现；指针静止 2 秒后全部隐藏，光标为 `none` |
| 信息层 | 宽屏时画面让位、不被遮挡；窄屏是抽屉；没有公开字段时不显示参数线；直方图在亮度和 RGB 之间切换 |
| 减少动态效果 | 翻页时没有 transition（读取计算样式） |
| 慢网络（3G 节流）和图片 404 | 加载前保持纯黑，失败时显示提示，翻页不受影响 |
| 结尾帧 | 三个入口都正确；在结尾继续向下进入下一组 |
| 跨作者切换 | 上边显示新作者名，读屏的 live 区域包含作者名 |
| URL | 刷新后停在同一帧；分享出去的链接不带 wall |
| 隐私 | 页面 DOM 和所有网络请求中不出现 `latitude`、`longitude`、`/o/`、`original` 的预取 |

截图保存在 CI 产物中，不作为像素回归的基准。

**Go**：`internal/webui` 测试 SPA 回退、静态资源缓存头、`/api` 和 `/m` 不被回退拦截、CSP 头。

**CI**：新增 `web` job，内容为 `npm ci`、类型检查、Vitest、构建、包体检查、Playwright（Chromium 和 WebKit）。
