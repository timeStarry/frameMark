# 子项目 5：工具重做（边框与拼图）

日期：2026-10-20　上位文档：`2026-10-13-markr-redesign-design.md` §1、§8、§9 第 5 行；SP4a 规格（归档、上传）；旧工具审查 `.superpowers/sdd/2026-10-20-sp5-tools/old-tools-audit.md`。

## 1. 定位与范围

- `/tools` 下两个工具：**边框**（原「水印」改名）和**拼图**。顶栏「Markr · 工具 · 我的」保留「工具」入口，首页和展墙不推荐工具。
- **免登录**：只用本地文件，处理全部在浏览器内完成，不发起任何上传或 API 写请求。
- **登录后**：额外可以「从归档选」，也可以把成品「存入归档」，之后像普通照片一样放进合集。
- SP5 完成后删除旧应用：`src/`、`server/`、旧 `tests/`、根目录 Vite 构建、旧 Pages 部署。`web/` 和 Go 服务是唯一的应用。

不在范围：HEIC/RAW、画布上直接拖动裁切、自定义字体、动态图、文字水印（防盗用文字水印只由服务端「下载水印」负责）。

## 2. 两个工具

### 2.1 边框

- 单张照片。
- 边框样式：纯色、渐变、模糊（取照片本身模糊铺底）、底条。宽度 0–20% 短边，圆角 0–10% 短边。
- 题签：最多 200 字，多行，3 种系统字体，字号 0.5–8% 短边，颜色，不透明度，9 个位置（具名单选）。题签只画在边框区域内；放不下时缩小字号，到下限仍放不下就提示「题签放不下，请加宽边框或缩短文字」，不压到照片上。去除控制字符和 bidi 控制字符。
- 拍摄参数行：机身、镜头、焦距、光圈、快门、ISO，默认全部关闭，逐项勾选后才画进图片；显示值可以手改。换照片时清空手改值。
- 4 个预设。

### 2.2 拼图

- 2–12 张。布局：网格（1–6 列）、横排、竖排。间距、外边距、圆角、背景色，可选透明背景（只在 PNG/WebP 时可选）。
- 每张图：焦点 X/Y（0–100%）、铺满或完整显示；可前移/后移；画布格子可点选。
- 尺寸：预设（1:1、4:5、3:2、16:9）和自定义（64–8192），可锁比例。

### 2.3 共用

- 输入：JPEG、PNG、静态 WebP。单文件 ≤60MB，源图 ≤60MP，这与服务端上限一致。解码前先读文件头预检，损坏、动态、超限文件直接拒绝并说明原因。
- 输出：JPEG/PNG/WebP，质量可调，长边可调。**默认长边自动选择**：输出不超过 16MP，长边不超过 8192；需要缩小时，在导出区显示「将缩小到 W×H」。
- 预览：长边 1600，每个素材只解码一次，缓存预览位图。调参数只重画，不再重新解码。导出时从原图重新解码一次。
- 撤销：最多 50 步。滑块拖完算一步。⌘Z / Ctrl+Z 在任何控件里都生效，文本框里的打字除外。
- 状态只在内存里，刷新就丢。离开页面时，如果有未导出的修改，会提示确认。
- 导出：「下载」一步完成。登录后多一个「存入归档」（§4）。

### 2.4 隐私

- 导出图由 canvas 重新编码，不带任何元数据。测试会断言这一点。
- 读 EXIF 用白名单，`gps:false`，不读位置和序列号。拍摄参数只有作者勾选后才会画进图片。
- 免登录模式不发起任何 `/api` 写请求，也不访问存储桶。

## 3. 从归档选（登录后）

- 工具页的照片入口有两个：「选择文件」和「从归档选」。后者打开一个归档选择抽屉，复用 SP4a 的归档筛选和网格，只列出 ready 照片。边框选 1 张，拼图选 2–12 张。
- 读取原图：新接口 `GET /api/photos/{id}/source`，只允许作者本人访问。服务端校验作者身份后，302 跳转到 5 分钟有效的预签名 GET 地址，不加 `Content-Disposition: attachment`。工具用 `fetch(..., { credentials: 'omit' })` 读取跳转后的地址，拿到 Blob 后走和本地文件相同的预检和解码流程。
- 存储桶跨域规则：originals 桶的 `AllowedMethods` 增加 `GET`，`DEPLOY.md` 同步更新。CSP 的 `connect-src` 已包含 S3 源。
- 来源记录：每个素材记住它的 `photoId`；本地文件没有 `photoId`。

## 4. 存入归档（登录后）

- 点「存入归档」后，弹出一个小对话框：
  - **标题**：默认边框为「原标题 · 边框」，拼图为「拼图 · N 张」。
  - **格式**：JPEG、WebP 或 PNG。
  - 一行说明：「公开字段沿用你的上传偏好；下载水印不会再叠加到这张图上。」
- 上传沿用 SP4a 的流程：SHA-256 → `POST /api/uploads` → 直传 PUT → complete → 轮询直到 ready。成功后显示「已存入归档」，并附「去归档查看」链接。
- 后端改动：
  1. `POST /api/uploads` 新增两个可选字段：
     - `title`：0–120 字，用 cleanText 清理；不提供时仍从文件名推出。
     - `derivedFrom`：最多 12 个照片 id，必须是调用者自己的 ready 照片，否则返回 400「来源照片无效。」。
  2. 新表 `photo_sources(photo_id, source_id, position)` 记录来源。
  3. **拍摄参数**：恰好有 1 个来源时，worker 处理完成后从来源照片复制白名单 EXIF 和拍摄时间（`photo_exif` 中位置以外的所有列）。位置永远不复制。直方图由新图自己计算。有多个来源或没有来源时，不复制拍摄参数。
  4. **下载水印**：`POST /api/uploads` 再加可选布尔字段 `toolOutput`，存入 `photos.tool_output`。工具成品（不论来源是归档还是本地文件）都带 `toolOutput: true`，这类照片不生成带水印的下载变体，避免叠两层文字。
  5. 测试覆盖：标题；来源校验，包括别人的照片和未处理完的照片；单来源复制 EXIF 且不带位置；多来源不复制；工具成品不生成水印变体；未带这些字段的普通上传行为不变。
- 公开字段：沿用作者上传偏好的快照，和普通上传一样，放进合集后可以逐张覆盖。

## 5. 前端结构

```
web/src/tools/
  engine/   preflight.ts、decode.ts（方向处理）、geometry.ts、render-frame.ts、render-collage.ts、encode.ts、
            exif.ts（白名单）、history.ts、jobs.ts（Jobs / SerialGate）、previewCache.ts
  FrameTool.vue、CollageTool.vue、ToolShell.vue（左画布 / 右面板；手机上面板在底部）、
  ArchivePicker.vue、SaveToArchive.vue、controls/*.vue
web/src/routes/ToolsRoute.vue   /tools（两个工具的入口）
router.ts                       /tools、/tools/frame、/tools/collage
```

- 旧引擎中有测试覆盖的部分移植过来，改为 TS 并整理格式，测试改用 vitest，可以继续使用 happy-dom 和 canvas mock。需要真实像素的比对放到 Playwright 里做，不给 web/ 引入 sharp 或 @napi-rs/canvas。
- 工具代码单独打包。`/`、`/c/:id`、`/me` 的关键路径包体不变。
- exifr 是新依赖（固定版本），只在工具页的 chunk 里加载。

## 6. 视觉与无障碍

- 暗房色板，圆角 0，焦点外框统一。
- 每个控件都有可见的 label。数值控件是 range 加 number 输入，并带实时数值。位置选择用具名单选组（「左上」…「右下」）。
- 手机上画布在上，面板从底部弹出；导出按钮固定在面板底部。
- 预览、导出和上传进度通过 `aria-live` 播报。

## 7. 删除旧应用

SP5 合并前一并删除：

- `src/`、`server/`、`tests/`（旧 node 测试）、`scripts/`（只服务旧应用的部分）
- 根目录的 `index.html`、`vite.config.js`、`public/`（旧资源），以及根 `package.json` 中只属于旧应用的依赖和脚本
- `.github/workflows/deploy.yml`（Pages 部署旧应用）和 `platform-ci.yml` 里跑旧测试的 job

保留：`web/`、`internal/`、`cmd/`、`docs/`、`ops/`（逐项确认）。删除前先用 grep 确认没有引用；`DEPLOY.md` 改写为只描述 Go 服务加 `web/` 的部署。

## 8. 测试

- 单元测试（vitest）覆盖：
  - 移植的预检、方向、几何、历史、任务
  - 默认尺寸策略（20MP 原图加 6% 边框 → 自动缩到 16MP 以内）
  - 题签碰撞与缩字
  - 模糊半径按输出尺度换算
  - 预览缓存（每个素材只解码一次）
  - 撤销在控件里也能生效
  - 换图后清空手改值
  - 存入归档的状态流
  - 归档选择器
- Go：§4 第 5 项列出的测试。
- Playwright（三浏览器）：
  - 免登录：加框后下载。断言 Blob 无 EXIF；断言没有 `/api` 写请求，也不访问 S3。
  - 登录：从归档选 1 张 → 加框 → 存入。归档出现新照片，标题正确，参数来自原片且无位置。
  - 拼图 6 张 → 存入。
  - 预览和导出一致：同一参数下，比较缩小后的导出图与预览的像素差，必须在阈值以内。
  - 键盘全流程；360 / 1440 宽度无横向滚动；减少动态效果。
- 包体：各关键路径保持在 80KB 以内，工具 chunk 单独计量。

## 9. 决定记录

- 两种用法都要：免登录本地工具，加上登录后的「从归档选 / 存入归档」。
- 工具只做边框题签，防盗用文字水印只由服务端下载水印负责，工具成品不再叠加下载水印。
- 成品记录来源。单来源时沿用原片的拍摄参数，但不带位置。
- 顶栏保留「工具」入口。SP5 完成后删除旧应用。
