# Markr 本地工具工作区规范

设计日期：2026-10-01。状态：设计基线，尚未实现；本提交先于工具重构。适用于边框水印、拼图及后续工具。与摄影平台共用深色设计变量，平台数据、登录与 API 不变。

## 需求盘点与边界

旧水印具备单图导入、模糊/纯色/渐变/底条边框、圆角、文字/字体/颜色/透明度/位置、EXIF字段、预设和导出。旧拼图具备多图、排序/删除、网格/横排/竖排、间距、背景、圆角和尺寸设置。这是需求清单，不是旧 UI 或代码的兼容约束。

当前缺陷：独立长面板与重复图像加载；操作历史缺失；深度监听触发异步预览缺少统一任务版本；拼图卸载清理不足；预览/导出重复逻辑；失败 alert、非语义点击控件和拖动排序缺少键盘替代；在线字体依赖与本地使用目标不一致。新实现删除旧视图、专属 composables/components/constants，依引用检查删除旧工具专属样式和依赖；不得误删平台共享变量、EXIF库或许可证。

所有处理仅本地内存，导入、预览、导出不得请求上传 API。无需账号；不调用工作室会话。刷新后不承诺恢复项目。作品分享是另行明确触发的未来能力。仅静态应用资源可能联网，默认字体采用系统字体，不加载远程字体。

## 工作区与视觉

继承 design-system.scss：背景 #090a0b，面板 #121416，文字 #eeeee9，辅助 #959b9f，边线 #282d31，强调 #ccd4c4。8px 间距基准，控件高至少40px、触摸目标44px，主动作只用于导出；不将选中颜色改成全局强调色。

桌面 >=1100px：上方工具标题/本地说明/撤销重做/导出；下方三列 216px 素材栏、minmax(0,1fr) 画布、300px 检查器。素材可滚动，画布留出安静背景；画布下方状态栏提供尺寸、适应/100%/缩放。中屏 760–1099px：素材改横向缩略条，画布与检查器双列。窄屏 <760px：画布在上，素材/属性为可切换面板，导出入口始终可见但不遮画布；无嵌套全页滚动、无横向溢出。360px 必测。

空状态呈现导入区与一句操作说明，不使用营销功能长列表。选择文件为原生 button+input；支持 drop，非法拖入有明确反馈。预览标注“预览”，实际导出尺寸在导出面板显示。缩放仅改变视口，不影响文档；fit、25/50/100/200%，超出视口可滚动，首次导入和布局变化默认fit。

## 共享控件合同

分组使用有标题的 fieldset，折叠为 button，aria-expanded；保持主要分组展开，不制造下拉菜单层叠。数字+滑块配对，同一单位与上下限，输入过程中允许临时空字符串，提交时校验且保留上次有效值；不静默把非法数值转为0。颜色提供原生颜色输入和可编辑 HEX；选择项使用 select/radio，九宫格为具名 radio。控件 label/描述/错误通过 id 关联。

素材项显示缩略图、文件名、像素尺寸、选中状态；添加、替换、删除、前移/后移为具名按钮。拖动是增强，排序按钮是必备。失败文件逐条报告，已成功素材保留；同一文件再次选择仍触发导入。重复素材允许，但给出重复名称提示。水印允许一个素材，替换前确认是否保留当前设置（默认保留）；拼图支持多选、一次导入按文件顺序追加。

## 状态与历史

文档状态与视口、忙碌、资源缓存分离。状态流：empty → importing → ready；ready → rendering → ready；ready → exporting → exported；任何任务可进入failed/cancelled，保留上次有效文档和预览。错误不清空全部素材。任务使用递增id，仅当前id可以提交结果；旧任务完成立即释放资源。

历史包含设置、素材引用/顺序、焦点裁切；不包含Blob、位图、缩放、折叠或忙碌状态。上限50步；滑块一次拖动/数字一次提交为一步，预设一次为一步。撤销删除需保留被历史引用的File；历史淘汰后释放引用。重置设置保留素材并可撤销；清空项目需要确认且可撤销。导出锁定快照；取消导出后可立即编辑，迟到结果不能触发下载。

Cmd/Ctrl+Z撤销、Shift+Cmd/Ctrl+Z重做，输入/textarea/contenteditable内交给原生文本编辑。Esc关闭导出面板或取消任务；不劫持浏览器默认保存快捷键。Tab顺序标题动作→素材→画布操作→属性，焦点环可见。删除选中项后焦点到相邻素材或添加按钮。对话框管理初始焦点、焦点循环、关闭归还；状态用aria-live polite，错误role=alert，画布提供文档文字描述，不依赖颜色表达选中。尊重减少动态效果。

## 水印操作模型

导入→选择预设→设置边框→文字→拍摄参数→预览→导出。默认纯色 #f3f1ea、边框短边6%、圆角0、水印为空、EXIF关闭，避免未经同意把相机或日期信息烧入图像。

边框：纯色/双颜色线性渐变/模糊背景/底条；宽度0–20%短边，底条高度0–30%，内容圆角0–10%。模糊背景cover，前景原比例contain，模糊半径按短边比例缩放；若浏览器不支持滤镜明确禁用该效果，不假装有模糊。纯色/渐变边框扩展画布，不裁切原图。底条上左右统一边距、底条额外高度。文档尺寸按几何公式统一计算。

文字：最多200字符，可换行，系统无衬线/衬线/等宽，字号0.5–8%短边、透明度0–100%、颜色、九宫格位置/底条左中右；安全内边距与文字实际宽度计算，超出可用宽度换行，过长有提示。拍摄参数白名单：相机/镜头/焦距/光圈/快门/ISO，缺失字段不可选；可手动编辑显示值，不修改原文件。位置/日期/序列号不读取入UI。文字与参数碰撞时采用两行堆叠，预览与导出同一布局函数。

预设：留白、暗色、柔焦、底部题签，明确列出修改分组；不覆盖用户文字/素材/EXIF选择。切换边框不丢掉非当前类型设置。P1实现这四类和上述设置；后置logo水印、自定义字体文件、批量水印、旋转/修图。

## 拼图操作模型

导入多图→排序→布局→每格构图→背景/间距→输出→导出。默认网格2列、1080×1080、间距16px、外边距24px、圆角0、背景 #f3f1ea、cover居中。网格列1–6；横排/竖排各一维布局；不满行空格显示背景，不复制图片。裁切通过每素材0–100%焦点X/Y配对数值/滑块控制，另提供contain留白；后续可增加画布拖拽裁切。选择画布单元格同步素材和检查器；本期若点选未实现必须标记，列表选择始终有效。

输出预设方形1080×1080、横幅1920×1080、竖幅1080×1920、自定义；单独宽高，保持比例开关。间距/外边距0–200px，圆角0–100px；验证有效单元宽高>0，否则禁止导出并定位错误，禁止负数或NaN绘制。重排后裁切设置跟随素材id。移除最后一张回空态，撤销可恢复。

选择只切换检查对象，重排只改变顺序，单格裁切只改变对应素材焦点，三者是独立操作。切换网格/横排/竖排保留素材id、顺序、每图焦点和cover/contain；只重新计算格子几何；输出尺寸不随模式静默变化。触屏使用点击选中与明确按钮，不依赖hover浮层。

## 导出、进度与失败

共享非阻塞导出面板：文件名、尺寸、JPEG/PNG/WebP、质量（JPEG/WebP 1–100，默认92；PNG隐藏质量）、JPEG背景明确不透明。水印默认原图加框尺寸，拼图默认所选尺寸；长边可改，比例锁定。格式能力运行时检测，toBlob/convertToBlob返回MIME不符时明确失败或让用户选择PNG，不伪装扩展名。

阶段：校验→解码第n/N张→绘制第n/N层→编码→准备下载。n/N只表示真实完成数量；编码API不暴露进度，显示不定进度“正在编码”，禁止计时假百分比。成功后显示真实Blob字节、像素尺寸和再次下载；新文档改动标记旧导出已过期，不能下载误以为最新的缓存。取消按钮一直可见；Worker可终止，主线程编码不能物理中断时逻辑取消丢弃结果并释放资源，明确说明。

保守可配置默认：单文件20MiB、源图40MP、素材最多12、输出16MP且长边<=8192px，估计工作集预算256MiB。文件字节/数量先校验，尺寸从头部安全读取后在完整解码前拒绝超限；未知尺寸格式在受控串行解码后校验，不承诺恶意文件零峰值内存。输出超限提示降低尺寸，不自动偷偷缩小。RAW/SVG/动画/HEIC不在本期，PNG/JPEG/WebP静态成片；任何资源不足可重试较小导出，文档不丢失。

透明背景为显式选项：PNG/WebP可保留alpha，JPEG必须选择不透明底色；工作区棋盘格仅为透明提示，不写入导出。导出从原File重新解码到目标所需分辨率，禁止截图预览或放大预览位图冒充原尺寸结果。输出坐标系是文档实际像素，视口变换独立。文字预览/导出均等待document.fonts.ready及选定字体就绪再测量；无法就绪有错误与重试，测试中文、多行与长文字，不能导出时悄悄换字体。

## 验收与分期

设计提交不代表实现验收。本轮实现按共享shell/状态/引擎→水印→拼图→旧实现清除→验证逐步提交。每项交付记录实际完成/未完成。后续工具必须复用状态、控件、资源生命周期与导出合同，不复制引擎。

自动测试：文档几何、cover/contain及焦点、预设不覆盖文本、undo事务/删除恢复/上限、超限/错误MIME、任务迟到/取消、EXIF隐私白名单；类型检查vue-tsc、构建及既有API测试。图像集：带方向1–8的JPEG、透明PNG、WebP、损坏与截断文件、40MP边界、大于限额、12图及第13张、连续替换、反复导入清空/撤销/卸载。资源测试检查每bitmap.close和URL revoke调用配对，不以调用计数冒充真实浏览器堆内存。

真实浏览器验收：用户Mac浏览器，桌面1440和窄屏360，文件导入→更改→撤销→取消导出→重新导出→本地打开结果；检查旋转、文本与预览一致、透明/JPEG背景、真实文件类型、键盘/焦点、无上传网络请求。性能记录机器/浏览器版本、图尺寸数量、预览/导出耗时和内存观察；目标预览调节在150ms节流后启动、输入保持可用，不设无证据的性能保证。浏览器工具或文件权限不足时逐项记未测，不以构建通过代替E2E。

导出验收读取文件实际像素宽高、alpha和MIME，不能仅看UI标签或文件扩展名；在同一输出坐标下比较缩小导出与预览的几何/文字布局。清理验收列出移除旧组件、composables、样式和依赖及全仓引用搜索结果，保留许可证证据。
