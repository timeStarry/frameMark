# Markr 全站视觉与交互重构

设计基线：2026-10-04，起点 `b4143d9`，分支 `feat/markr-platform-phase1`。本轮先完成源码审阅、两组独立设计/交互评审及本设计，再实现。既有账户、作品、素材和 SMTP 配置沿用，不发送测试邮件，不改变试验环境安全设置。

## 设计判断与参考边界

主题是 **安静的展墙，连续的观看**。摄影提供颜色和情绪，界面负责方向、署名和必要操作。保留已确认的深色方向，不因参考站点使用浅色而换皮。辨识度来自图幅、留白、疏密与观看位置的连续性；不把非线性动效解释成全页反复飞入。

本执行环境通过网页正文读取了 [Criterion Channel](https://www.criterionchannel.com/) 的精选入口和影片列表层级、[Kinfolk](https://www.kinfolk.com/) 的图片与短文案组织。上层独立评审以云端浏览器核实了 [Alec Soth 项目 Gallery / Index](https://www.alecsoth.com/photography/projects/i-know-how-furiously-your-heart-is-beating) 和 [MUBI Now Showing](https://mubi.com/en/us/showing)。只借鉴图片优先和内容节奏，不照搬营销区。云端参考审阅不等于本机产品浏览器验收；本 Mac 当前没有可调用的浏览器控制工具。

技术依据：[减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/prefers-reduced-motion)、[Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)、[合成友好动画](https://web.dev/articles/animations-guide)、[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[LCP 图片加载](https://web.dev/articles/optimize-lcp)。View Transition 仅作为可选渐进增强；首期优先保证返回位置、焦点与图片加载可靠，不为追求跨页特效增加不稳定依赖。

## 统一视觉规则

| 元素 | 规则 |
| --- | --- |
| 色彩 | 背景 `#090a0b`，工作面 `#121416`，浮层 `#1a1d20`；主文 `#eeeee9`，辅助文 `#a0a4a8`；低对比 faint 仅装饰使用 |
| 强调 | `#ccd4c4` 用于主操作、选中和焦点；主页自定义色仅少量点缀 |
| 字体 | 系统字体；标题 28–36px，正文 15px / 1.7，导航/控件 13–14px，署名 12–13px；常用字重 400/500 |
| 间距 | 4/8/12/16/24/32/48/64px；桌面页侧距 40–64px，移动端 16px |
| 照片 | 无卡片背景、阴影、描边、内边距，圆角 0–2px；预览保留图幅，观看完整 contain；封面可裁切但作品页必须完整 |
| 控件 | 6px 圆角，主要触摸目标至少 44px；输入控件保留明确边界；布局主要靠留白 |
| 文案 | 删除宣传眉题、重复标题、副标题、重复 CTA；状态和隐私信息仍明确可见 |

半透明图注仅用于有局部暗渐变保障的封面，普通文字目标对比度 4.5:1。不能靠把必要文字变淡来制造安静。键盘焦点清晰；触屏无 hover 依赖。

## 页面与信息密度

| 页面 | 内容与行为 |
| --- | --- |
| 广场 | 保留屏幕阅读器标题；可见界面直接从精选照片或内容流开始。精选封面仅一句简介（正文首行，标题回退）与公开姓名署名；图片进入作品，署名进入主页。删除“广场 / 发现独特的视角”、精选眉题、按钮和尾部工具入口。没有精选不生成假封面；成功空结果只显示真实空状态。 |
| 内容流 | 图片按校正后比例形成有节奏的行，保持 API/DOM 阅读顺序，移动单列。极端全景保留比例并限制列宽。简短标题和署名在图片外，组图数量只一处。文字作品采用简洁文字块。提供真实分页“继续浏览”；新页只动画新节点，错误可原位重试。避免自动无限加载和滚动劫持。 |
| 摄影师主页 | 封面可选；姓名简介放在封面外，无封面不留下巨大空框。保留布局、配色、模块顺序定制。作品集使用当前可见成员作品封面，不能泄露私密成员。 |
| 作品集 | 紧凑返回、标题、说明后直接显示成员；沿用成员权限过滤。 |
| 观看 | 精简页头；照片占据主要视野，固定可发现的前后操作与计数，图片 contain。详情在图像下方。支持组图方向键、加载/失败/重试、文字作品与允许时的原图下载；无自动播放。返回恢复内容流位置与原卡片焦点，直接访问回广场。 |
| 工具箱 | 标题、两项工具、简短用途与结果线稿。没有用户授权样片时不用虚构摄影资产。只显示一次“无需登录，不自动上传”。 |
| 两工具 | 素材 / 画布 / 检查器形成连续工作面；空画布纯色，透明输出可检查透明区域。保留所有导入、排序、替换、构图、数字/颜色、撤销、取消、导出功能；次要设置可折叠。移动面板选择紧邻所控制面板。导出维持非模态区及既有焦点恢复。 |
| 登录 | 约 400px 直接表单，移除营销左栏。保留服务关闭、注册/验证、会话恢复、返回地址、重复提交保护及试验确认；复选框使用独立行。 |
| 工作台 | 作品、作品集、主页文字分区；列表简洁，编辑器按内容、发布、许可组织。读取状态与保存/上传状态分开；保留草稿输入，保存失败可重试。执行中禁用冲突编辑切换，迟到结果不能写到新草稿。未保存离开有明确提示。 |
| 通用 | 精简固定导航，无品牌宣传语；观看页弱化全站导航。页尾仅保留必要署名信息，不重复工具/工作台入口。未知路由有可返回状态。 |

## 动效语言

| 场景 | 时长 / 曲线 | 限制 |
| --- | --- | --- |
| 控件反馈 | 140ms，`cubic-bezier(.2,0,0,1)` | 颜色/边界反馈 |
| 内容首次进入 | 420ms，`cubic-bezier(.22,1,.36,1)` | 透明度及向上 10px；错峰每项 28ms、最多 112ms |
| 追加内容 | 340ms，同上 | 只新项，错峰最多 96ms；已有项位置稳定 |
| 精细指针图片 hover | 300ms，同上 | 最大 1.01 倍，框内轻微放大；外部图幅与布局不变 |
| 观看图片替换 | 180ms | 解码完成后短淡入，加载时保留稳定画框；无横甩/弹跳 |
| 面板显隐 | 240ms，同上 | 透明度与最多 8px 位移；关闭更短 |

只动画 transform/opacity，不做视差、滚动劫持、整屏 blur、持续 will-change、长队列延迟。首屏主图 eager/high priority，后续 lazy，明确图像宽高与比例。IntersectionObserver 为渐进增强；不支持时内容直接可见，键盘聚焦立即可见，销毁清理观察器。减少动态效果或数据节省模式取消位移、错峰和平滑滚动。每次返回不重播已见内容。工具参数变化只更新预览，不触发页面入场。

## 架构与数据边界

继续 Vue 3 + 现有 Node/Express/SQLite 单体，不增加动画或布局依赖。拆分公共摄影组件、公共浏览页面与工作台，隔离平台 CSS，消除 `.editor-grid` 与工具冲突。共享媒体组件处理尺寸、加载、失败与重试；共享动效只改变呈现，不改变读取和编辑生命周期。工具保留原渲染/资源释放引擎，不套全局 KeepAlive 或 fullPath 重建。

API 增补公开作者姓名、可见封面与展示图尺寸；`photographer` 仍是 owner ID，仅作路由标识，不能当 @昵称。没有公开姓名则使用“摄影师”。新素材记录 rotate 后的展示宽高；旧素材可从展示文件只读推导，不能把 EXIF 原图宽高直接当展示比例。原文件不改写，位置元数据不公开。

广场分页只返回仍满足公开、发布、允许分发的作品，按稳定顺序切页；客户端不持久缓存作品/权限数据，返回时重新校验。公开展示和广场分发继续独立；精选仍由 featuredRank 决定，不自动把未精选作品当横幅。作品集封面只从可读成员产生；仅链接仍不是安全访问控制。

## 验收矩阵与交付口径

自动检查包括 npm check/typecheck/test/build、API 权限/分页/尺寸测试、DOM 读取错误与重试、观看切换、工作台重复/失败/迟到结果、账户回归、工具回归。构建通过不等于视觉验收。

浏览器矩阵：360/390/768/1440px 与 200% 缩放；横/竖/全景/黑白/复杂照片，长名字、无封面、文字作品、慢网断图、成功空态；10 次快速进入/返回/切图；直接 URL 刷新；键盘全流程、触控目标、减少动态效果；两工具真实导入、预览、取消、生成和下载。当前 Mac 工具目录无浏览器控制能力，这些渲染/焦点/流畅度/真实下载项目必须列为未测，不能用云端参考浏览或 DOM 测试冒充。

部署沿用 `timestarry@server` 独立 `markr-phase1.service`、现有 18140 端口、trial-data、身份试验与 SMTP 引用；新 release 原子切换并保留原 release 回滚。不改防火墙、Tailscale、账户、邮件、其他生产服务。推送仅本分支，PR #4 保持 draft；确认远端 SHA、CI、运行版本、健康、资源和匿名权限。
